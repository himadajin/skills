# Monochrome Frontend Design

白い紙にインクで刷ったような無彩色のデザインシステムを Web UI に適用する。
装飾を意味論に還元し、色・太さ・動きの代わりに
「サイズ・濃度・線種」で階層と状態を表現する。

作業を始める前に `references/design-system.md` を読み、仕様の全体を把握する。
以下はその要約と、逸脱してはならない核ルールである。

## 核ルール

1. **パレットは無彩色 7 トークンで完結させる。**
   紙面: `#fafafa`（地）/ `#171717`（インク）/ `#f5f5f5`（muted）/ `#ebebeb`（ヘアライン）。
   ターミナル面: `#101010`（地）/ `#282828`（枠）/ `#ffc799`（カーソルオレンジ）。
   オレンジはターミナル面のシンタックス強調とカーソルにのみ許される唯一の色。
   紙面側に新しい色を追加しない。リンクも青にしない。
2. **フォントは 3 ファミリー固定。**
   本文・見出し: Geist、日本語フォールバック: Noto Sans JP、コードとメタ情報: Geist Mono。
   使用ウェイトは 400 / 500 / 600 のみ。**700 とイタリックは使わない。**
3. **装飾の意味論: 「破線＝リンク、実線＝現在地、濃度＝状態」。**
   - リンクの下線は破線 1px・offset 4px・インク 35%、hover で 100% に濃くなる。
   - 現在地（アクティブなナビ・タブ）は実線 2px・インク 100% の下線。
   - hr や区切りは実線ヘアライン `#ebebeb`。破線を非インタラクティブ要素に使わない。
   - 状態変化はすべて濃度（opacity / gray 段階）で表現し、色相を変えない。
4. **タイポグラフィの声: 「大きく・軽く・締める」。**
   ページタイトルはサイズで語り（30〜48px）、ウェイトは 500、tracking は -0.02em 前後。
   メタ情報（パンくず・タグ・日付・ラベル）は Geist Mono・大文字・tracking +0.08em・11〜13px・グレー。
   見出しを sans の全大文字にしない（大文字は mono ラベル専用の声）。
5. **動きと影はほぼゼロ。**
   hover による移動・浮き上がり・バウンスは使わない。transition は色のみ 150〜200ms。
   影は使わないか、使っても `0 1px 2px rgba(0,0,0,0.04)` 以下。
   深度はポラリティ反転（白地の中の黒いターミナル面）で表現する。
6. **コードブロックは黒いターミナル面。**
   `#101010` 地 + `#282828` ヘアライン枠 + mono 大文字の言語ラベルヘッダー。
   ブロック内のテキスト選択は白地・黒文字にポラリティ反転させる。
   シンタックステーマは白＋オレンジ一点の vesper 系。

## 適用手順

対象に応じて入口を選ぶ。

- **単発の HTML ファイル**:
  `assets/starter.html` をベースにコピーして書き換える。
  フォント読み込み（Google Fonts）とトークン CSS が組み込み済みの自己完結テンプレート。
- **Tailwind CSS v4 のプロジェクト**:
  `references/tailwind.md` を読み、`@theme` へのトークン組み込みとユーティリティ定義に従う。
- **その他のフレームワーク・既存サイト**:
  `assets/tokens.css` を取り込み、`references/design-system.md` の
  コンポーネント仕様に沿って要素スタイルを組む。

いずれの場合も、コンポーネントの具体仕様（ナビ・パンくず・タグ・
コードブロック・OG カード）は `references/design-system.md` を参照する。

## 完成前チェックリスト

出力を確定する前に以下を確認する。

- [ ] `font-weight: 700` / `font-style: italic` が存在しない
- [ ] 紙面側に無彩色以外の色（青リンク・緑成功色など）が存在しない
- [ ] 破線がリンク以外に、実線下線が現在地以外に使われていない
- [ ] hover で要素が移動・変形していない
- [ ] メタ情報が mono 大文字ラベルになっており、本文と声が分離している
- [ ] コードブロックがターミナル面の仕様（黒地・ヘアライン・mono ヘッダー）に従っている
- [ ] 見出し階層がサイズと余白（上広・下狭）で表現されている
