# インタラクション拡張（Web/UI のみ）

hover と遷移が存在する媒体（Web サイト・Web アプリ・インタラクティブな HTML）で
核の仕様（`design-system.md`）に重ねる語彙。
スライド・資料・図版・印刷では休眠するので読まない。

## インクの意味論

**破線は行ける場所、実線はいま居る場所、濃度は状態、
面と枠は計器を表す。**
線種と濃度がそのまま意味を持つため、色や動きに頼らずに
インタラクションを表現できる。

| 表現 | 意味 | 仕様 |
|---|---|---|
| 破線下線 | リンク。ここは飛べる | 1px dashed・offset 4px・インク 35% |
| 実線下線 2px | 現在地・選択中。いまここ | インク 100%・offset 4px |
| 面 + 枠線 | 計器。その場で動く道具 | コピーボタン等のみ。リンクには使わない |

hover は次の統一則に従う。

- **本文中のリンク**: 読み流しの中でリンクを見つけられるよう、破線は常時見せる。
  hover でインクと破線が 100% に濃くなる。
- **クローム内のリンク**: ナビ・パンくず・目次のように全部がリンクの場所では、
  平常時は下線なしの薄いインク（70%）。
  **hover でインクが濃くなり、破線下線が現れる。**
  「触れたら破線が浮かぶ」がこの言語の「押せそうな質感」である。
- 現在地要素の hover は実線を保つ（破線に変えない）。
- 状態変化はすべて濃度（透明度）で表現し、色相を変えない。
- transition は color / border-color / text-decoration-color / background-color
  のみ、130〜200ms。要素の移動・拡大・浮き上がりは使わない。
- 深度は影ではなくガラス（後述）とヘアラインで表現する。

「破線を見たら押せる」を成立させるため、
破線を hr など非インタラクティブ要素に使わない。
例外は図版・グラフの内部で、そこではインクの意味を別に定めてよい
（`design-system.md` の「インクと濃度」）。
破線がリンクを意味するのは、図版の枠の外だけである。

## 選択色・フォーカス

- テキスト選択: `::selection` を指定せず、OS・ブラウザの既定に任せる。
- フォーカスリング: 実線 2px・インク・offset 1〜2px。破線や色付きにしない。

## 計器

面 + 枠線は「その場で動く道具」（コピーボタン・トグル等）の専有物。

- ヘアライン枠 + 薄いインク、hover で muted 地 + インク 100%。角丸なし。
- リンクの hover に面を出さない。
- ページ内ツールバー（言語トグル・フィルタ等）も計器として組む
  （「クロームの原則」参照）。

## クロームの原則

画面上部は 3 つの帯に分ける。

```
━━━━━━━━━━━━━━━  ① クローム帯 … サイトの道具（ヘッダー）
                   ② ステージ … 一定の高さの静寂（48px）
 TITLE BLOCK       ③ コンテンツ帯 … 紙。ページの主役
```

- **クローム帯はガラスの浮遊層。**
  半透明の地（背景色 75%）+ backdrop blur 12px。
  ページ最上部では境界線なしで紙に溶け、
  スクロールしてコンテンツが下に潜り込む時だけ、
  ヘアラインがフェードインして層になる。
  高さは 56px 前後の 1 行に収め、サイトタイトルは本文サイズ（16px semibold）。
- **ステージは全ページ同一の高さ**（48px）。
  ページごとに揺れると遷移のたびにリズムが崩れる。
- **パンくずはタイトルの eyebrow。**
  ステージの下・タイトルの 8px 上に置き、コンテンツ帯に所属させる。
  ヘッダー直下に置くと「ヘッダーの 2 行目」に見えて 3 帯が崩れる。
- **建築と計器を区別する。**
  サイトレベルの物（ヘッダー）だけが全幅のバー。
  ページレベルの道具（言語トグル・フィルタ等）はコンテンツ幅に収まる
  小さな計器にし、sticky にする場合はヘッダー直下に吸着させる
  （`top: ヘッダー高さ`）。従属関係を位置と大きさで示す。
- ナビの現在地は実線下線、hover は「インク濃く + 破線出現」（意味論の統一則）。
- モバイルとデスクトップは同一構造にする。項目が短ければナビは常時表示し、
  ハンバーガーを既定にしない。
- シャープさを旨とする言語なので角丸は使わない。ガラス帯・計器・コード面すべて直角。

## Do / Don't

### Do

- 「触れたら破線が浮かぶ」でインタラクションの質感を作る。
- 3 帯構造を守り、ガラスとヘアラインで深度を表現する。

### Don't

- 破線を装飾として乱用しない。図版の枠の外では破線はリンクの証。
- リンクの hover に背景面を出さない。面は計器の専有物。
- hover による移動・浮き上がり・バウンスを使わない。
