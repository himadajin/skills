# デザインシステム仕様

白黒のシャープなミニマリズムを軸にした個人デザインシステムの完全仕様。
「白い紙 + mono 大文字ラベル + 黒いターミナルの窯」が全体の構図で、
装飾はすべて意味論（何を意味するか）に還元されている。

## カラートークン

### 紙面（ライト面）

| トークン | 値 | 役割 |
|---|---|---|
| `--background` | `#fafafa` | ページの地。純白ではなく 98% 白 |
| `--foreground` | `#171717` | インク。テキスト・アクセント・現在地表示のすべて |
| `--muted` | `#f5f5f5` | インラインコードの地、控えめな面 |
| `--border` | `#ebebeb` | ヘアライン。区切り線・枠線・表罫線 |

アクセント色は独立させず `--foreground` と同値（インクがアクセント）。
ただし CSS 上はトークンを分けておくと、後からの調整余地が残る。

### ターミナル面（ダーク面）

| トークン | 値 | 役割 |
|---|---|---|
| `--terminal` | `#101010` | コードブロック・カードの地 |
| `--terminal-border` | `#282828` | ターミナル面のヘアライン枠 |
| `--terminal-mute` | `#7d8187` | ターミナル面のグレーテキスト（ラベル・フッター） |
| `--cursor` | `#ffc799` | カーソル・シンタックス強調。システム全体で唯一の色 |

### 選択色・フォーカス

- テキスト選択: 紙面では黒地 `#171717` に地色の文字（ポラリティ反転）。
  ターミナル面内では逆に白地 `#f5f5f5` に黒文字。
- フォーカスリング: 実線 2px・インク・offset 1〜2px。破線や色付きにしない。

## フォント

```css
--font-sans:
  "Geist", "Noto Sans JP", system-ui, -apple-system, "Hiragino Sans",
  "Yu Gothic", Meiryo, sans-serif;
--font-mono:
  "Geist Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

- 欧文グリフは Geist、日本語グリフは Noto Sans JP にフォールバックさせる
  （この順序が重要。逆にすると欧文も Noto で描画されてしまう）。
- 使用ウェイトは 400 / 500 / 600 のみ。700・イタリックは読み込みもしない。
- セルフホストするなら Fontsource の variable 版
  （`@fontsource-variable/geist` 等）、単発 HTML なら Google Fonts。

## タイポグラフィ階層

| 役割 | サイズ | ウェイト | tracking | 備考 |
|---|---|---|---|---|
| ページタイトル | 30〜48px | 500 | -0.02em 前後 | 大きく軽く。太字にしない |
| h2（セクション） | 24px | 600 | -0.02em | 上余白 2.5rem・下余白 0.75rem |
| h3 | 20px | 600 | -0.02em | 上余白 2rem |
| h4 以下 | 16〜17px | 600 | 0 | |
| 本文 | 16px | 400 | 0 | 行間 1.7〜1.75 |
| ページ説明文 | 13px | 400 | 0 | mono・グレー 60%。イタリックにしない |
| メタラベル | 11〜13px | 400〜500 | +0.08em | mono・大文字・グレー 45〜70% |
| コード | 13〜14px | 400 | 0 | mono |

原則:

- **階層はサイズと余白で作り、太さで作らない。** 700 は存在しない。
- **ネガティブ tracking は大きい文字ほど強く**（48px で -0.02em、
  それ以下は -0.01em 程度）。本文はいじらない。
- **mono は「技術の声」専用。** メタ情報・ラベル・コードにのみ使い、
  本文段落を mono にしない。
- **sans の全大文字見出しは禁止。** 大文字は mono ラベルとの組み合わせ専用。

### メタラベル（署名的要素）

パンくず・タグ・日付・言語ラベル・ボタンラベルなどのメタ情報は
すべて同一仕様のラベルにする:

```css
.meta-label {
  font-family: var(--font-mono);
  text-transform: uppercase;
  letter-spacing: 0.08em;
}
```

パンくずの区切りは `»` や `>` ではなく `/`（ターミナルのパスの声）。

## 装飾の意味論

**「破線＝リンク、実線＝現在地、濃度＝状態」。**
画面上の線種と濃度がそのまま意味を持つため、
色や動きに頼らずにインタラクションを表現できる。

| 線種 | 意味 | 仕様 |
|---|---|---|
| 破線下線 | ここは飛べる（リンク） | 1px dashed・offset 4px・インク 35% → hover 100% |
| 実線下線 2px | いまここ（アクティブ） | インク 100%・offset はナビなら 8px |
| 実線ヘアライン 1px | 構造の区切り | `#ebebeb`。hr・枠線・表罫線 |

- 破線を hr など非インタラクティブ要素に使わない
  （「破線を見たら押せる」を成立させるため）。
- hover は濃度変化のみ（35% → 100%、60% → 100% など）。
  要素の移動・拡大・浮き上がりは使わない。
- transition は color / border-color / background-color のみ、150〜200ms。
- 影は原則なし。使う場合も `0 1px 2px rgba(0,0,0,0.04)` を上限とする。
  面の深度はポラリティ反転（白地の中の黒い面）で表現する。

## 余白とレイアウト

- 本文幅: 最大 768px（読み物中心なら 672px も可）、左右 padding 16px。
- リズムは「大きな間 + 密な内部」:
  セクション間（h2 の上）は広く 2.5rem、見出し直下は狭く 0.75rem。
  ページタイトル下の説明文のあとに 2.5rem 置いてから本文に入る。
- ページ上部（ヘッダーからタイトルまで）にも 3rem 程度の余白を取り、
  詰めて始めない。

## コンポーネント仕様

### ヘッダー・ナビゲーション

- 地はページと同色（`#fafafa`）。枠や影を付けない。
- サイトタイトル: 600・tracking -0.02em。
- ナビリンク: 通常はインク 100%・下線なし。
  現在地のみ実線 2px 下線（offset 8px）。

### パンくず

`HOME / SECTION / PAGE-TITLE` を meta-label 仕様（mono・大文字・12px・グレー 65%）で。
リンク部分は hover で濃度 100%。

### リンク（本文中）

破線下線仕様（上記）。文字色はインクのまま変えない。
訪問済み色・青リンクは使わない。

### タグ・バッジ

meta-label 仕様 + 下辺のみ破線 1px（リンクなので破線）。
サイズは 12〜14px。hover で境界と文字が 100% に。

### ボタン

- 第一ボタン: インク地 `#171717`・白文字・radius 6px。
- 第二ボタン: 白地・インク文字・ヘアライン枠・radius 6px。
- ラベルが短い英語なら meta-label 仕様にしてよい。

### コードブロック（ターミナル面）

```
┌───────────────────────────────┐ ← border: 1px #282828, radius 6px
│ BASH                     [⧉] │ ← ヘッダー: 白 3% の地、mono 大文字ラベル(白 45%)
├───────────────────────────────┤
│ $ npm run build               │ ← 地 #101010、白テキスト
│                               │    シンタックス強調は #ffc799 一点
└───────────────────────────────┘
```

- コピーボタン: 白 15% 枠・白 5% 地のゴースト。hover で白 10% 地。
- ブロック内の `::selection` は白地 `#f5f5f5`・黒文字に反転。
- ブロック内のスクロールバーはダークグレー。
- シンタックスハイライトのテーマは vesper 系
  （黒地・白・オレンジ `#ffc799` 一点。Shiki なら `vesper` をそのまま使う）。
- インラインコードは紙面側に残す: `#f5f5f5` 地・radius 4px・padding 2〜4px。
  ブロックとの対比で「窯」が際立つ。

## OG 画像・カード

SNS カードやヒーローカードはターミナル面で統一する。1200x630 の場合:

- 地 `#101010`、外周 40px の内側に 1px `#282828` のヘアライン枠。
- 枠内 padding 52〜60px、上・中・下の 3 段構成:
  - 上: mono 大文字ラベル（`SITE / SECTION` など、26px・`#7d8187`・tracking 2px）
  - 中: タイトル（Geist 500・72〜96px・tracking -1.5px・白）+
    直後にオレンジ `#ffc799` のブロックカーソル（幅 22px 程度の矩形）
  - 下: mono フッター（ホスト名・著者名、24px・`#7d8187`）
- カーソル矩形は文字グリフ `▍` ではなく div/rect で描く
  （フォントサブセットに依存しないため）。

## Do / Don't

### Do

- 色を足したくなったら、まず濃度（グレー段階）で解決できないか考える。
- 大きさで階層を作る。太さは 600 を天井に控えめに使う。
- mono 大文字ラベルでメタ情報の声を分離する。
- 黒いターミナル面をページの奥行きとして使う（ポラリティ反転が深度）。
- 破線・実線・濃度の三要素だけでインタラクション状態を表現する。

### Don't

- 700・イタリック・全大文字の sans 見出しを使わない。
- 紙面側に青リンク・緑成功・赤エラーなどの色を導入しない
  （エラー表示が必要な UI では例外を検討するが、まず濃度と実線枠で試す）。
- 波線・グラデーション・重い drop-shadow・hover アニメーションを使わない。
- 破線を装飾として乱用しない。破線はリンクの証。
- オレンジ `#ffc799` を紙面側に持ち出さない。ターミナル面の中だけの灯り。
