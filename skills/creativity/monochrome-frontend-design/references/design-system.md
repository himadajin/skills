# デザインシステム仕様

白黒のシャープなミニマリズムを軸にした個人デザイン言語の完全仕様。
媒体（Web・スライド・図版・ドキュメント）を問わず適用できるよう、
原則は比率と役割で記述し、16px 本文を基準にした代表値を併記する。

全体の構図は「白い紙 + インクの線 + mono 大文字の計測ラベル」。
目指す佇まいは広告ではなく、よく組まれた技術ドキュメントである。

## カラートークン

| トークン | 値 | 役割 |
|---|---|---|
| `--background` | `#fafafa` | 紙。純白ではなく 98% 白 |
| `--foreground` | `#171717` | インク。テキスト・枠・現在地表示のすべて |
| `--muted` | `#f5f5f5` | インラインコードの地、控えめな面 |
| `--border` | `#ebebeb` | ヘアライン。区切り線・表罫線 |
| `--cursor` | `#ffc799` | カーソルの点。システム唯一の色（下記） |

- アクセント色は独立させずインクと同値（インクがアクセント）。
  CSS 上はトークンを分けておくと後からの調整余地が残る。
- 中間の濃度は新トークンを作らず、インクの透明度
  （35% / 45〜55% / 65〜70%）で作る。

### カーソルの点

オレンジ `#ffc799` は**ワンポイントの目印にのみ**使う:
ブロックカーソルの矩形、ロゴ的な一点、署名としての灯り。
リンク・状態表示・見出し・強調など機能的な要素には決して使わない。
1 画面に 1 点までを目安とし、迷ったら使わない。

### 選択色・フォーカス

- テキスト選択: インク地 `#171717` に紙色の文字（ポラリティ反転）。
- フォーカスリング: 実線 2px・インク・offset 1〜2px。破線や色付きにしない。

## フォントと声の分離

```css
--font-sans:
  "Geist", "Noto Sans JP", system-ui, -apple-system, "Hiragino Sans",
  "Yu Gothic", Meiryo, sans-serif;
--font-mono:
  "Geist Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

- 欧文グリフは Geist、日本語グリフは Noto Sans JP にフォールバックさせる
  （この順序が重要。逆にすると欧文も Noto で描画されてしまう）。
- 使用ウェイトは 400 / 500 / 600 のみ。700・イタリックは読み込みもしない。
- **mono は「技術の声」専用。** メタ情報・ラベル・コードにのみ使い、
  本文段落を mono にしない。sans の全大文字見出しも禁止
  （大文字は mono ラベル専用の声）。

### メタラベル（単一スケール）

パンくず・タグ・日付・言語名・ボタンラベルなどのメタ情報は
**すべて同一仕様の 1 スケール**にする:

```css
.meta-label {
  font-family: var(--font-mono);
  font-size: 0.6875rem; /* 本文の約 70%（16px 基準で 11px） */
  font-weight: 400;
  letter-spacing: 0.1em;
  line-height: 1rem;
  text-transform: uppercase;
}
```

- サイズを複数作らない。差は濃度で付ける:
  静的な情報 45〜55% / クリックできるもの 65%。
- 小さくするほど tracking は広げる（11px なら 0.10em）。
  0.12em 以上は計器的になり、長い語では可読性が落ちる。
- uppercase は同 px の小文字より約 2px 大きく見える。
  「小さすぎる」と感じたらまず濃度を上げる（サイズを上げない）。
- パンくずの区切りは `»` や `>` ではなく `/`（ターミナルのパスの声）。
- タグの記号はアイコンではなく mono の `#` 文字を接頭に置く
  （テキストと同じサイズ・色で自動的にスケールする）。

## タイポグラフィ階層

原則: **階層はサイズの大差ではなく、控えめなサイズ差 + 太さ + 吸着余白で作る。**
16px 本文を基準とした代表値:

| 役割 | 比率 | 代表値 | ウェイト | 備考 |
|---|---|---|---|---|
| ページタイトル | 1.5x（天井） | 24px | 600 | tracking -0.02em。レスポンシブで育てない |
| h2（セクション） | 1.25x | 20px | 600 | tracking -0.02em |
| h3 | 1.125x | 18px | 600 | |
| h4 以下 | 1x | 16px | 600 | |
| 本文 | 1x | 16px | 400 | 行間 1.65（和欧混在の下限 1.6） |
| ページ説明文 | 0.8x | 13px | 400 | mono・グレー 60%。イタリック禁止 |
| メタラベル | 0.7x | 11px | 400 | mono・大文字・上記単一スケール |
| コード | 0.8x | 13〜14px | 400 | mono |

- タイトルと説明文の落差を広げすぎない。
  「大きな見出し + 小さな mono キャプション + 広い余白」は
  マーケティングのヒーロー構図であり、この言語では避ける。
- ネガティブ tracking は大きい文字ほど強く（24px で -0.02em 程度）。
  本文はいじらない。

## インクの意味論

**「破線＝行ける、実線＝いま居る、濃度＝状態、面と枠＝計器」。**
線種と濃度がそのまま意味を持つため、色や動きに頼らずに
インタラクションを表現できる。

| 表現 | 意味 | 仕様 |
|---|---|---|
| 破線下線 | ここは飛べる（リンク） | 1px dashed・offset 4px・インク 35% |
| 実線下線 2px | いまここ（現在地・選択中） | インク 100%・offset 4px |
| 実線ヘアライン 1px | 構造の区切り | `#ebebeb`。hr・罫線 |
| 面 + 枠線 | その場で動く道具（計器） | コピーボタン等のみ。リンクには使わない |

hover の統一則:

- **本文中のリンク**: 破線は常時見せる（読み流しの中でリンクを見つけるため）。
  hover でインクと破線が 100% に濃くなる。
- **クローム内のリンク**（ナビ・パンくず・目次など、全部がリンクの場所）:
  平常時は下線なしの薄いインク（65〜70%）。
  **hover でインクが濃くなり、破線下線が現れる。**
  「触れたら破線が浮かぶ」がこの言語の「押せそうな質感」である。
- 現在地要素の hover は実線を保つ（破線に変えない）。
- 状態変化はすべて濃度（透明度）で表現し、色相を変えない。
- transition は color / border-color / text-decoration-color / background-color
  のみ、130〜200ms。要素の移動・拡大・浮き上がりは使わない。
- 影は使わない。深度はガラス（後述）とヘアラインで表現する。

破線を hr など非インタラクティブ要素に使わない
（「破線を見たら押せる」を成立させるため）。

## 余白の言語

**値は役割別 6 段ラダーから選ぶ**（16px 本文基準の代表値）:

| 段 | 代表値 | 役割 |
|---|---|---|
| 1 | 4px | 同じものの内部（リスト項目間、タイトル→キャプション） |
| 2 | 8px | 見出しとその中身の接続（h2→本文、eyebrow→タイトル） |
| 3 | 16px | ブロックの区切り（段落、コード面、カード間） |
| 4 | 24px | 話題の小さな切り替え（h3 の前、説明文→本文） |
| 5 | 32px | 話題の大きな切り替え（h2 の前、hr、ページ先頭） |
| 6 | 48px | ページレベルの区切り（ステージ、main の下端） |

原則:

- **見出しは中身に吸着させる。** 上広:下狭 = 4:1
  （h2 なら上 32 / 下 8、h3 なら上 24 / 下 8）。
  下余白が広いと見出しが浮いて所属を失う。
- **リスト項目間はブロック間より明確に狭く**（4px vs 16px）。
  項目間が段落間に近づくと、箇条書きが「独立した文の羅列」に見える。
- **コンテンツは密に、骨格はゆったり。**
  ヘッダー・フッター・ページ外周の余白は詰めない。
  全部を均等に詰めると「窮屈」になり、コンテンツだけ詰めると「密度」になる。
- 本文幅は最大 768px（読み物中心なら 672px も可）、左右 padding 16px。

## クロームの原則（UI）

インタラクティブな UI（サイト・アプリ）を作るときのみ適用する。
画面上部は 3 つの帯に分ける:

```
━━━━━━━━━━━━━━━  ① クローム帯 … サイトの道具（ヘッダー）
                   ② ステージ … 一定の高さの静寂（48px）
 TITLE BLOCK       ③ コンテンツ帯 … 紙。ページの主役
```

- **クローム帯はガラスの浮遊層。**
  半透明の地（背景色 75%）+ backdrop blur 12px。
  ページ最上部では境界線なしで紙に溶け、スクロールした瞬間に
  ヘアラインがフェードインする（コンテンツが下に潜り込む時だけ層として立ち上がる）。
  高さは 56px 前後の 1 行に収め、サイトタイトルは本文サイズ（16px semibold）。
- **ステージは全ページ同一の高さ**（48px）。
  ページごとに揺れると遷移のたびにリズムが崩れる。
- **パンくずはタイトルの眉（eyebrow）。**
  ステージの下・タイトルの 8px 上に置き、コンテンツ帯に所属させる。
  ヘッダー直下に置くと「ヘッダーの 2 行目」に見えて 3 帯が崩れる。
- **建築と計器を区別する。**
  サイトレベルの物（ヘッダー）だけが全幅のバー。
  ページレベルの道具（言語トグル・フィルタ等）はコンテンツ幅に収まる
  小さな計器にし、sticky にする場合はヘッダー直下に吸着させる
  （`top: ヘッダー高さ`）。従属関係を位置と大きさで示す。
- ナビの現在地は実線下線、hover は「インク濃く + 破線出現」（意味論の統一則）。
- モバイルとデスクトップは同一構造にする。項目が短ければナビは常時表示し、
  ハンバーガーを既定にしない。
- 角丸は使わない（シャープの言語）。ガラス帯・計器・コード面すべて直角。

## コード面

コードは「白い紙の上の引用面」。黒地のターミナル面は作らない。

```
┌───────────────────────────────┐ ← border: 1px インク #171717、角丸なし
│ BASH                     [⧉] │ ← ヘッダー: 背景なし、ヘアライン下線のみ
├───────────────────────────────┤    言語ラベルは meta-label・インク 45%
│ $ npm run build               │ ← 地は紙と同色 #fafafa
│ ✓ Finished in 0.8s            │    シンタックスは抑制的ライトテーマ
└───────────────────────────────┘
```

- シンタックス配色は min-light 系（ほぼ黒 + グレー + 一色）。
  カラフルなテーマを使わない。
- コピーボタンは「計器」: ヘアライン枠 + 薄いインク、hover で muted 地。角丸なし。
- インラインコードは `#f5f5f5` 地・padding 2〜4px（角丸 4px までは許容）。
- コード面の前後余白はブロックの区切り（16px）。

## Do / Don't

### Do

- 色を足したくなったら、まず濃度（グレー段階）で解決できないか考える。
- 階層は控えめなサイズ差 + 太さ + 吸着余白で作る。600 が太さの天井。
- mono 大文字ラベルは単一スケールに固定し、濃度だけで差を付ける。
- 余白は必ずラダーの 6 値から選び、役割に対応させる。
- 「触れたら破線が浮かぶ」でインタラクションの質感を作る。
- UI では 3 帯構造を守り、ガラスとヘアラインで深度を表現する。

### Don't

- 700・イタリック・全大文字の sans 見出しを使わない。
- 青リンク・緑成功・赤エラーなどの色を導入しない
  （エラー表示が必要な UI では例外を検討するが、まず濃度と実線枠で試す）。
- オレンジを「カーソルの点」以外（リンク・状態・見出し）に使わない。
- 波線・グラデーション・drop-shadow・hover アニメーションを使わない。
- 破線を装飾として乱用しない。破線はリンクの証。
- リンクの hover に背景面を出さない。面は計器の専有物。
- 黒地のコード面・ターミナル風カードを作らない。
- ラベルのサイズを場所ごとに変えない（14px のタグと 11px のラベルの併存など）。
