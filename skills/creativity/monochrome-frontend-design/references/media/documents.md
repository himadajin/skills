# 資料（markdown → HTML / PDF）での適用

markdown で書かれた技術資料・ノートを HTML や PDF に整形するときの規則。
pandoc などの変換器を想定するが、規則は変換器に依存しない。
実装のベースは `../../assets/document.css` で、このファイルの規則を CSS にしたもの。
コピーして使い、変換器の出力に合わせてセレクタだけ調整する。

インタラクション拡張（`../interaction.md`）のうち、
**リンクの意味論（破線下線・hover でインク濃く）だけを借りる**。
ブラウザで読まれる資料にはリンクがあるからで、
クローム・ステージ・計器・ガラスはこの媒体には存在しない。
印刷・PDF では hover が死ぬだけで、破線下線は「参照の印」としてそのまま残る。

フォントの読み込みは利用側で行う（`document.css` はフォントを読み込まない）。
pandoc なら `--embed-resources` で woff2 を data URI として埋め込むと
出力 HTML が自己完結する。

## 見出しの割り当て

資料ではページタイトルが変換器のメタデータのタイトルブロックから来て、
本文見出しは h1 から始まる。核の 5 段スケールをひとつずらして割り当てる:

| 要素 | 役割 | サイズ | 上/下余白 |
|---|---|---|---|
| タイトルブロック | ページタイトル | 24px | 下 48px（ページレベル） |
| h1 | 見出し 大 | 20px | 32 / 8 |
| h2 | 見出し 中 | 18px | 24 / 8 |
| h3 | 見出し 小 | 17px | 24 / 8 |
| h4 | 見出し 最小 | 16px | 24 / 8 |
| h5 | 濃度で区別 | 16px・インク 70% | 24 / 8 |
| h6 | 声で区別 | メタラベルの声（11px mono 大文字） | 24 / 8 |

- h5 / h6 は、サイズが尽きたらまず濃度、次にメタラベルの声で区別するという
  核の導出の適用。サイズの新段を作らない。
- タイトルブロックは「著者・日付（メタラベル）→ タイトル」の順に
  8px 間隔で縦に組む。メタが上、タイトルが下——eyebrow の構図。

## 本文要素の組み方

- **表**: 14px。罫線は水平ヘアラインのみ（上端 + 各行下端）。
  縦罫線・ゼブラ・背景色は使わない。ヘッダー行はウェイト 600 だけで立てる。
- **引用（blockquote）**: 左に 2px・インク 35% の縦線、本文はインク 70%。
  背景面・イタリックは使わない。
- **脚注**: 13px・インク 70%。本文とは上ヘアラインで区切る。
- **タスクリスト**: チェックボックスも無彩色（`accent-color: インク`）。
- **定義リスト**: dt はウェイト 600、dd は 24px インデント。
- **画像・図版**: キャプションはメタラベル。図版内部では
  インクの意味を別に定めてよい（核の「インクと濃度」）。

## コード面の簡略化

コード面は核の仕様（白地 + 1px インク枠 + 角丸なし）のまま。
資料では計器（コピーボタン）が存在しないため、
ヘッダーは「言語ラベルのみ」になる:

- 言語が既知なら、ヘアライン下線付きヘッダーに mono 大文字ラベル
  （メタラベル・インク 50%）。
- **言語ラベルを出せないコードブロックは、ヘッダーなし・枠のみに簡略化する。**
  空のヘッダー帯を残さない。
- シンタックスハイライトの出力にウェイト・イタリックが混ざる変換器では、
  トークンスタイルを平文（400・正体）に正規化する。

## 変換器固有の注意（pandoc）

`document.css` に実装済み。他の変換器に移すときの参照:

- 言語ラベルは `pre` に付く言語クラスから `::before` で立てる。
  列挙にない言語は自動的に「ヘッダーなし」になる。
- pandoc が脚注の頭に挿す `hr` は、脚注面の上ヘアラインと二重になるため消す。
- タスクリストのチェックボックスは pandoc 既定 CSS が
  -1.6em ぶら下げてマーカー位置に置く
  （input は label に包まれるので子結合子では選べない）。
  ul のインデントは消さず、ぶら下げ幅だけリストのインデントに合わせる。
